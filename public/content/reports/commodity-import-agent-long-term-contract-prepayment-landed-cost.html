[!NOTE] 核心摘要 · INSIGHT

进口代理站在矿山和终端中间，赚的是价差，扛的是敞口。本篇把中间环节的四件事全部落到可复算的公式上：长协定价公式、到岸成本拆分、海关审价挤压、预付款资金占用。核心判断：代理的利润杀手排序变了——第一是审价，第二是长协锁量与提货脱节，第三才是海运与汇率。

矿山卖的是组合收入，终端买的是确定性，中间的人两头都要接。本篇是锆钛系列的进口代理专题，不讲行情方向，只讲方法：四个公式，代入你自己的参数就能重算。公式公开，参数自填。

第一部分｜本篇的方法：四个公式，一张敞口表

本篇的四个公式：

  • 长协开票价 = $P_{Base} \pm 品位调整 - 杂质扣罚$
  • 到岸成本 = FOB + 海运 + 税费 + 港杂 + 选矿加工（分币种）
  • 审价多缴税 = 申报价 $\times$ 调增比例 $\times$ 13%
  • 资金占用 $\approx CIF \times 预付比例$；占用周期 = 预付锁定 + 在途 + 滞留 + 加工 + 账期

[!NOTE] 发表口径声明：公式与结构公开；FOB/CIF 绝对区间、预付精确比例天数、审价精确调增区间与测算例、对手方与合同号不刊出；预付与审价用区间化表述并声明个案差异。

第二部分｜长协定价公式：溢价买的是确定性

图1｜长协在山腰、现货在谷底：季度议价带来约一个季度时滞

定价公式

$$Invoice\ Price = P_{Base} \pm 品位调整(ZrO_2+HfO_2、TiO_2) - 扣罚(Fe_2O_3、Al_2O_3、U+Th)$$

运作机制与溢价真相

  1. 机制：国际头部矿山对亚洲以季度议价或半年度指引为主，极少纯现货指数日更联动。
  2. 溢价真相：长协锁定的是精品级（66% 级）：粒度均一、低放射性，省去国内洗矿除杂损耗与环保核查风险；现货低价多为小矿中矿或副产低品位，与长协标的不是同一标准品。所谓溢价，本质是品位错配，不是品牌溢价。
  3. 下行期裂口：矿山凭合同挺价，中小选厂抛货回笼，现货踩踏——“长协在山腰、现货在谷底”。
  4. 时滞效应：季度议价意味着价格下行有约一个季度的时滞——现货已跌、长协未调，代理库存重估先行。

[!NOTE] 代理实操动作：向下游转嫁时，必须把品位、粒度、放射性写进合同标的，否则下游按现货低品位价压价，溢价即成代理亏损；议价锚定品位升贴水表，设置量弹性条款。

第三部分｜到岸成本拆分：六个节点，分币种

图2｜到岸成本：六个节点，分币种

以莫桑比克/西非标准锆英中矿（折 65% 标准品）为基准，成本节点与公式位置：

节点 公式位置 币种 核心风险点
FOB 离岸价 成本起点 美元 预付三至五成、锁定一至两月（区间化）
海运至湛江 CIF 组成 美元 船期、拼船配矿、滞期费
CIF 报关货价 计税基数 美元→人民币折算 汇率敞口，锁汇决定佣金留存
关税 + 增值税 税负（HS 26151000：0% + 13%） 人民币 海关审价调增（见第四部分）
港杂与短驳 落地费用 人民币（120—180 元/吨区间结构） 装卸、仓储堆存、放射性检验
选矿精选加工 加工费用 人民币（350—500 元/吨区间结构） 回收率损耗

[!NOTE] 结构结论：美元段（FOB+海运）决定货值，人民币段（港杂+加工）决定落地弹性，税费段（审价）是第一大利润变量。三段分开算，不要混成一个“到岸价”。

第四部分｜海关审价挤压：第一大利润变量

规则口径：湛江霞山非标中矿报关时，海关若认定市场现货参考价高于合同申报成交价，可调增完税价格约一至两成（区间化表述，个案差异大）。

计算公式

$$单吨多缴增值税 = 申报价 \times 调增比例 \times 13%$$

方法演示（符号化）

设申报 CIF 为 $P$，调增比例为 $r$，则完税价为 $P \times (1+r)$。 多缴增值税 = $P \times r \times 13%$。

在选矿与贸易综合毛利仅个位数百分比的微利环境下，单吨新增税负可吃掉数成毛利，且多缴进项难向萧条的下游转嫁。

[!NOTE] 代理动作（方法版）：

  1. 申报前备齐成交价证据链（合同、付款、第三方价、品位检测与扣罚计算），与同口岸同品位成交区间对齐；
  2. 非标中矿单独准备品位与回收率说明，避免按精品参考价核定；
  3. 代理协议写明审价调增的税负分担与追溯期限；
  4. 保留价格磋商与复议路径的时间戳——审价争议不只算税额，还算滞港堆存与船期连锁成本。

第五部分｜预付款与资金占用：敞口公式

图3｜资金占用周期：五段相加

  • 结构：预付三至五成、锁定一至两月（区间化表述）；到港后另有审价滞留、选矿加工与下游账期。
  • 公式： $$单吨资金占用 \approx CIF \times 预付比例 + 港杂垫付 + 加工费垫付$$ $$占用周期 = 预付锁定天数 + 海运在途 + 报关/审价滞留 + 选矿周期 + 下游账期$$
  • 下行期风险：锁定价高于到港时现货，库存重估与下游压价同时发生；长协季度议价时滞放大此效应。
  • 缓释清单：分批预付与装船节点挂钩、锁汇覆盖预付至结汇段、量弹性与延期提货条款、审价税负分担条款、下游背靠背品位标的。

第六部分｜HS 口径陷阱（与第一篇共用）

  • HS 26151000（锆）：陷阱在“毛重 vs 折纯”——海关统计为实物毛重，定价与消费须折 65% 标准品；西非、东南亚原砂/HMC 占比上升，折纯增幅显著低于毛重增幅。
  • HS 26140000（钛）：天然金红石（$\text{TiO}_2 \ge 95%$）与钛铁矿（$\text{TiO}_2\ 45%—50%$）同税号混装，只看税号均价严重失真，必须按申报品名与品位二次分拆。
  • 分国别：澳洲精品（高端特瓷/精密铸造/氯化法）、莫桑比克华南核心（海运直达、低放射性）、西非/南非 HMC 与中矿（国内分选）。

第七部分｜对进口贸易的实操含义：中间人的四本账

  1. 定价账：公式先行，品位、粒度、放射性写进标的；溢价部分单独列示，不与货值混谈。
  2. 税费账：审价是第一大利润变量，申报材料与协议条款提前准备，不做事后补救。
  3. 资金账：预付、滞留、加工、账期五段相加算总占用，下行周期先算资金成本再算货值。
  4. 库存账：长协时滞约一个季度，现货已跌、长协未调时，库存重估先行，备货节奏留出议价窗口。

第八部分｜反证：什么会推翻当前解读

按本系列的方法，每个判断都配推翻条件。反证只能逐条下调对应解释的权重，不能自动推出价格方向。

# 当前判断 推翻条件
1 审价是第一大利润变量 口岸审价口径实质性放宽，或精品参考价体系覆盖中矿
2 长协溢价本质是品位错配 现货市场出现同品位、同确定性的低价供给
3 季度议价时滞约一个季度 矿山转向现货指数日更联动
4 下行期预付即敞口 市场转入上行周期，锁定价低于到港现货
