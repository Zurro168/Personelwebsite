钨矿知识库 V0.1

1. 基本信息

项目 内容
中文 钨
英文 Tungsten / Wolfram
化学符号 W
常见计价氧化物 WO3
主要矿物 黑钨矿、白钨矿
贸易核心产品 钨精矿、APT、氧化钨、钨粉、碳化钨、钨铁

2. 核心贸易单位

单位 定义
WMT Wet Metric Ton，实物湿吨
DMT Dry Metric Ton，干吨
MTU / 吨度 Metric Tonne Unit，1吨货中1%的WO3含量
标吨 国内钨精矿常用标准吨，通常按65% WO3，即65吨度

3. 关键换算

DMT = WMT x (1 - Moisture)
WO3吨度 = DMT x WO3% x 100
65%标吨 = WO3吨度 / 65
吨度价 = 标吨价 / 65
货值 = WO3吨度 x 吨度价 x 计价系数

4. 计价注意事项

  1. 国内钨精矿报价“万元/吨”通常指“万元/标吨”，不是实物吨。
  2. 低品位非标矿不能简单按65%标矿全额计价，需要计价系数或加工费折扣。
  3. 国际APT价格是中游产品价格，不能直接等同于粗精矿价格。
  4. 国际买方对粗矿的计价系数由品位、杂质、收率、加工成本、物流、合规和市场缺货程度决定。

    5. 5. 43% WO3非标矿关注点

    维度 关注点
    品位 低于65%标准精矿，需确认冶炼厂可接受
    杂质 As、S、P、Mo、Sn、Cu、Pb、Bi等可能触发罚扣或拒收
    水分 影响DMT和实际结算
    粒度 影响取样、公允检验和冶炼处理
    来源 钨属于3TG，需强化产地和供应链尽调
    文件 矿权、货权、出口许可、产地证明、运输记录

    6. 主要风险

    1. 标吨和实物吨混淆导致货值严重偏差。
    2. 用APT价格直接套粗精矿，导致高估销售收入。
    3. 供应商提供的品位报告不可靠。
    4. 低品位、杂质和水分导致买方大幅压价。
    5. 非洲内陆物流成本和边境风险侵蚀利润。

      6. 6. RMAP、CoC、冲突矿产尽调无法闭环导致海外买方拒收。
