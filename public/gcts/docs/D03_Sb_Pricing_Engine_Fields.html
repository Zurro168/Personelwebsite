D03 国际报价引擎（Sb）字段设计 V0.1

目标

建立锑矿贸易报价模型。用户输入品位、数量、价格、物流、融资和杂费后，系统自动输出采购上限、销售报价、毛利、现金需求和敏感性结果。

输入字段

模块 字段 说明
货物 Commodity Sb / Antimony
货物 Grade Sb品位，例如52%、53%
货物 Moisture 水分
货物 Impurity 杂质，如As、Pb、S等
货物 Quantity_WMT 湿吨
货物 Quantity_DMT 干吨
价格 Benchmark_Price 国际参考价
价格 Payability 计价系数
价格 Penalty 罚扣
价格 Purchase_Terms FOB / CIF / CFR / EXW
价格 Sales_Terms FOB / CIF / CFR / DAP
物流 Inland_Freight 内陆运输
物流 Border_Cost 边境与清关成本
物流 Port_Cost 港口费用
物流 Ocean_Freight 海运费
物流 Insurance 保险
检验 Sampling_Cost 取样成本
检验 Assay_Cost 检验成本
财务 Finance_Rate 融资利率
财务 Finance_Days 占款天数
财务 FX 汇率
财务 Tax 税费
目标 Target_Margin 目标毛利率

输出字段

Payable_Metal
Gross_Metal_Value
Total_Logistics_Cost
Total_Finance_Cost
Total_Transaction_Cost
Max_Purchase_Price
Suggested_Sales_Price
Gross_Profit
Gross_Margin
Cash_Requirement
Break_Even_Price
Sensitivity_Table

基础计算逻辑

DMT = WMT * (1 - Moisture)
Payable_Metal = DMT * Grade * Payability
Gross_Metal_Value = Payable_Metal * Benchmark_Price
Total_Cost = Purchase_Cost + Logistics_Cost + Finance_Cost + Tax + Inspection_Cost + Other_Cost
Gross_Profit = Sales_Revenue - Total_Cost
Gross_Margin = Gross_Profit / Sales_Revenue

人工复核点

  1. Benchmark_Price是否来自有效价格源。
  2. 品位、水分、杂质是否有第三方检验依据。
  3. 罚扣和计价系数是否符合客户或冶炼厂实际接受标准。
  4. 物流成本是否包含边境、港口、保险、滞期和安全成本。
  5. 融资天数是否覆盖从预付款到回款的完整周期。
