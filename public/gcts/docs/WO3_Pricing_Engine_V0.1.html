WO3 报价引擎 V0.1

目标

建立钨矿贸易统一报价模型，避免“标吨、实物吨、吨度、APT价格、粗矿计价系数”混用。

输入字段

模块 字段 说明
货物 Commodity 黑钨矿 / 白钨矿 / 混合钨矿
货物 WMT 实物吨
货物 Moisture 水分
货物 WO3_Grade WO3品位
货物 Impurity 杂质明细
国内价 China_65_Conc_Price 国内65%钨精矿标吨价
国内价 China_Payability 国内计价系数
国际价 APT_USD_MTU 海外APT美元/吨度
国际价 Overseas_Payability 海外粗矿计价系数
汇率 FX_USDCNY 美元兑人民币
成本 Inland_Freight 矿山至港口内陆运费
成本 Border_Cost 边境与清关成本
成本 Port_Cost 港口费用
成本 Ocean_Freight 海运费
成本 Insurance 保险
成本 Inspection 取样检验
成本 Finance_Cost 融资成本
成本 Compliance_Cost 合规与文件成本

核心计算

DMT = WMT x (1 - Moisture)
WO3_MTU = DMT x WO3_Grade x 100
Standard_Ton_65 = WO3_MTU / 65

China_Base_MTU_Price = China_65_Conc_Price / 65
China_Settlement_MTU_Price = China_Base_MTU_Price x China_Payability
China_Gross_Value = WO3_MTU x China_Settlement_MTU_Price

Overseas_Settlement_USD_MTU = APT_USD_MTU x Overseas_Payability
Overseas_Gross_Value_USD = WO3_MTU x Overseas_Settlement_USD_MTU
Overseas_Gross_Value_CNY = Overseas_Gross_Value_USD x FX_USDCNY

Route_Net_Value = Gross_Value - Logistics_Cost - Finance_Cost - Compliance_Cost - Risk_Buffer
